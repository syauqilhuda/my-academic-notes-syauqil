# My Academic Notes Syauqil

Website akademik yang dirancang untuk menampilkan dan mendokumentasikan catatan serta makalah dalam bentuk digital. Project ini dikembangkan menggunakan HTML, CSS, dan JavaScript.

## Deskripsi Project

My Academic Notes Syauqil merupakan website yang berfungsi sebagai media penyimpanan dan penyajian materi akademik. Website ini memungkinkan pengguna untuk melihat daftar makalah serta membaca isi makalah yang tersedia melalui antarmuka web.

## Fitur

- Menampilkan daftar makalah akademik.
- Menampilkan detail dan isi makalah.
- Menyajikan abstrak, pendahuluan, pembahasan, kesimpulan, dan daftar pustaka sesuai data yang tersedia.
- Menyediakan tampilan yang dapat disesuaikan melalui CSS.
- Menggunakan JavaScript untuk mengelola data dan menampilkan konten secara dinamis.

## Teknologi yang Digunakan

- **HTML5** — Digunakan untuk membangun struktur halaman website.
- **CSS3** — Digunakan untuk mengatur desain, warna, tipografi, dan tata letak.
- **JavaScript** — Digunakan untuk mengelola data, interaksi, dan tampilan konten makalah.

## Struktur Project

```text
My-Academic-Notes-Syauqil/
├── index.html
├── style.css
├── script.js
└── README.md
```

### Penjelasan File

- `index.html`: Berisi struktur utama halaman website.
- `style.css`: Mengatur tampilan visual, warna, ukuran font, dan tata letak.
- `script.js`: Mengelola data makalah serta logika untuk menampilkan konten.
- `README.md`: Berisi dokumentasi project.

## Cara Menjalankan Website

1. Unduh atau salin repository project ke komputer.
2. Buka folder project menggunakan Visual Studio Code.
3. Pastikan seluruh file utama berada pada lokasi yang sesuai.
4. Buka file `index.html` melalui browser atau gunakan ekstensi Live Server.
5. Jelajahi website dan pilih makalah yang ingin dibaca.

## Kustomisasi

Tampilan website dapat disesuaikan melalui file `style.css`, termasuk warna, ukuran font, jarak antarparagraf, dan tata letak halaman.

Data serta konten makalah dapat disesuaikan melalui file `script.js` mengikuti struktur data yang digunakan oleh website.
